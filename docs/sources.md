# 来源与署名

数据包括三种不同来源，需要分别理解：

1. **歌词文字、注音与分唱**：原歌词项目及其记录的上游资料，例如 Sekaipedia。使用原项目的演唱者定义，不通过声音识别猜测角色。
2. **歌词时间轴**：已保存的音乐平台或参考音源映射结果，包括 QQ 音乐、网易云音乐、酷狗音乐、LRCLIB，以及少量人工或官方 MV 对照结果。实际来源按各歌曲记录为准。
3. **中文译文**：原项目的译者署名，或原项目未提供歌词时使用的已保存第三方译文。

每首歌的 `sources.json` 从本次交付的来源清单导出，提供用途、平台、记录 ID、URL、许可和说明。只发布已记录的信息；空链接表示没有保存可直接引用的链接。它不是声学准确性认证，也不意味着列出的每个平台都有逐字数据。

`lyrics.json` 的 `sources` 是上游文字许可摘要，时间轴的来源应查 `sources.json` 或 Excel 的“来源明细”。原始检索、候选音源、模型文件和研究过程文件不包含在本仓库中。

已记录 CC BY-SA 等上游许可的内容，应保留相应署名、链接及许可说明。歌词文字、译文、录音和整理脚本并不自动共享同一个许可；本仓库未对全部内容授予统一许可。再发布时请按具体来源及权利人授权处理。
