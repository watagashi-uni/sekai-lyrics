# Sekai Lyrics

Project SEKAI 游戏音频用的同步歌词成品，包含日文、已有的中文译文、原项目的分唱标记，以及可用的逐字／逐词时间轴。

## 来源

- **歌词文本与中文译文**：大多来自 [pjsk.moe](https://pjsk.moe/) 的歌词项目（下文称“原项目”），包括日文歌词、中文译文及译者署名、分唱标记和注音。原项目的上游资料如 Sekaipedia 记录在各歌曲的 `sources.json` 中。
- **时间轴**：取自 QQ音乐、网易云音乐、酷狗音乐、LRCLIB 等音乐平台的逐字／逐句歌词，按算法与游戏音频比对，匹配游戏版的剪辑、裁切和时间偏移；少量歌曲经人工或官方 MV 对照。

每首歌的具体来源见 `sources.json`、`lyrics.json` 和 Excel。

每首歌的目录示例：


## 时间轴与版本

**全部游戏时间轴均从选定游戏音频文件的起点开始，包含前置空白。** 用 `audio.currentTime` 直接同步，不再减去 `fillerSec` 或 `filterSec`。如自行裁掉音频开头，则需要同步减去裁切秒数。

每首歌保留一个选定游戏版本作为默认，`vocalId` 或 `assetbundle` 表示该版本。所有演唱版本共用同一条伴奏和时间轴，只是歌手不同；已核验的附加演唱版本放在可选的 `versions` 中，只保存时长、演唱者和每个默认行的分唱（`singers`，按默认行下标）。分唱只用于它所属的版本。

## 生成播放资源

Node.js 20 或以上，无需安装依赖：

```sh
node scripts/build-playback.mjs
node scripts/validate.mjs
```

`playback/version.json` 列出每首歌的内容哈希，歌曲资源为 `<musicId>.<hash>.json`。更新时先上传歌曲文件，最后上传 `version.json`。

## 当前边界

- 这些数据是现有成果的整理与播放映射，不代表已经逐字人工听审，也不承诺收齐全部和声、拟声词或所有翻唱版本。
- 带逐字的句子按原始时间单元播放；文字对应关系不能可靠确认的部分保留逐句显示。
- 明确标注“重复两次”且来源确有两段对应时间轴的行，会在播放文本里展开；保留的双语原项目文件仍可用来核对原文。
- `ÅMARA(大未来電脳)` 的部分人造语采用 `XXXXXX` 占位并保留对应时间。
- 部分歌曲没有中文译文，或者只有部分句子有译文。播放器应允许隐藏译文。
- 原项目未提供歌词的 `イガク`（515）和 `アンヘル`（562）以已保存的平台歌词和第三方译文提供 LRC。

歌曲、歌词、译文及上游资料的权利归各自权利人；本仓库没有为所有内容声明统一的开源许可，具体以已记录的上游许可和权利人授权为准。
